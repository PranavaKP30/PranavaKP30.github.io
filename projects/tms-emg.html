TMS-EMG Acquisition & Control

Research Intern · April to May 2026 · C++, device drivers, serial and TCP

The Problem

The lab's TMS experiments ran on a setup that wasn't real-time, so it was hard to control stimulation precisely and record the muscle response in sync with it.

The Process

  • TMS driver: I wrote a serial driver for a Magstim BiStim² paired-pulse TMS device. It's built around a state machine with a checksummed command protocol, and I tested it with loopback before hooking it up to the real device.
  • EMG driver: I built a 16-channel acquisition module for a Delsys Trigno wireless EMG system. It uses two TCP sockets and a separate listener thread, so incoming data never stalls the real-time loop.

The Outcome

Both drivers now run in the lab's real-time Linux setup, so researchers can fire TMS from code and record EMG without lag during live experiments. They also ended up being the base for the closed-loop platform I built that summer.
