LOOP-IT Closed-Loop Interface

Co-lead · Summer 2026 · Embedded firmware, state machines, real-time signal processing

The Problem

Transcranial alternating current stimulation (tACS) can push brain rhythms around, but it works better when it's timed to the rhythm that's already there. The lab's neuroConn LOOP-IT stimulator can do closed-loop stimulation, but someone has to write the onboard code that reads EEG, figures out the right moment, and triggers stimulation. I co-led that with a grad student.

The Process

  • Onboard driver: I wrote the driver from scratch in the device's RALGOL firmware environment, with an interface block for passing parameters and status back and forth with the lab's software.
  • State machine: each trial goes through idle, pre-stim, stimulating, post-stim, and inter-trial states, so every trial runs the same way with predictable timing.
  • EEG features: the driver finds each subject's individual alpha peak frequency and tracks the phase of their alpha rhythm so stimulation can lock onto it.
  • Cycle generator: I refactored the waveform generator and fixed unit bugs (frequency in mHz, current in µA) so what the researcher enters is exactly what the device outputs.

The Outcome

The driver and state machine are done. What's left is confirming the physical channel mapping and trigger gating on the device. This one taught me to triple-check units. On a stimulator, being off by 1000x is not something you want to find out during an experiment.
