EEG-Modulated Neurostimulation Platform for Force Tracking

Visiting Researcher · June 2026 to present · Real-time C++, closed-loop control, signal processing

A real-time, closed-loop platform that brings multimodal brain stimulation, visuomotor force tracking, and EEG-driven modulation onto one synchronized timeline, and lets researchers design and run new experiments without writing code.

The Problem

Brain activity changes from moment to moment, but most stimulation experiments run with fixed settings. The lab's existing setup could only run one type of force task paired with one kind of stimulation, amplitude had to be adjusted by hand, and every new experiment meant an engineer writing new code from scratch. The lab needed a single platform that could combine stimulation, behavior, and live EEG, and that researchers could reconfigure on their own.

The Solution

I designed and built the platform end to end: five real-time C++ modules running on the RTXI framework on Xenomai real-time Linux, a closed-loop controller tying them together, and a Python orchestrator that sets up and launches everything.

  • EEG collector: streams 32 channels from a Brain Products ActiChamp amplifier over LSL and extracts frequency-band features in real time.
  • Force processor: collects and processes 6 force sensor inputs.
  • Stimulation engine: one unified engine driving 8 configurable channels, including tES, dual temporal interference (TI) channels, a sum-of-sines channel, and TMS triggering.
  • Task generator: lets researchers fully design each trial, from the target waveform to the stimulation paired with it.
  • Force display: a physics-calibrated, subject-facing display showing the target and the subject's live force.
  • Closed-loop control: stimulation amplitude follows live EEG band power, calibrated to each subject's baseline, with slew-rate limiting so output can never jump past safe bounds.
  • Python orchestrator: builds and launches the RTXI environment, configures every module, previews waveforms live, saves presets, and routes all hardware I/O in one step.

Impact

The platform replaced manual amplitude adjustment with automatic, safety-bounded closed-loop control, and turned a long, multi-step setup into a single reproducible workflow that anyone in the lab can run. Because tasks and stimulation are fully configurable, researchers can now build new experiments without an engineer, including paradigms that weren't possible before, like a subject tracing the exact stimulation waveform being delivered to their own brain in real time. The platform is used lab-wide and contributed to a federal grant application.

Building it taught me how much timing matters. Every module has to stay synchronized on one timeline, and when the output is stimulation delivered to a person, a late or wrong value is a safety issue, not just a bug.

Future Work

Right now, EEG acquisition has a fixed delay, so the closed-loop adjustments lag slightly behind the brain activity they respond to. Over the coming months, I'm building an ML model that forward-predicts EEG to estimate its current values, and connecting it to the real-time modules so modulation happens in true real time. The next step after that is extending the control beyond amplitude, so stimulation can also adapt in frequency and phase.

This is active lab research, so I can only share a simplified overview of the system here. I'm happy to go into more detail in an interview.
